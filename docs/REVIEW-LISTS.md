# Вложенные списки

Пункты обзора хранятся в `reviews[].prompts` как плоский массив. Необязательный `parentId` ссылается на пункт того же списка; отсутствие поля или `null` означает корень. Старые списки не требуют миграции. Вложенность ограничена 32 переходами от корня. Циклы, неизвестные родители и перенос между списками отклоняются.

Галочка раздела изменяет все конечные подпункты его ветки. Промежуточное состояние рассчитывается по потомкам. Поле `done` родителя равно `true`, только когда все его конечные подпункты отмечены. Общий прогресс учитывает конечные пункты; завершение обзора сбрасывает отметки всех узлов.

Веб и Android отправляют действия через существующую очередь изменений. Идентификатор и время действия сохраняются при повторной отправке; сервер проверяет ревизию и квитанции. Состояние целиком не заменяется.

## Операции MCP

Перед записью вызывается `life_read`, затем полученная ревизия передаётся в `life_act`.

| Действие | Поля |
| --- | --- |
| `review.create` | `title`, необязательный массив `prompts: [{title, children?: [...]}]` для создания дерева одним запросом |
| `review.prompt` | `id` списка, `title`, необязательный `parentId` — добавление пункта |
| `review.prompt` | `id`, `promptId`, `title` и/или `parentId` — редактирование без изменения отметки |
| `review.prompt` | `id`, `promptId`, `done` — отметка всей ветки; без полей редактирования и без `done` — переключение |
| `review.prompt.move` | `id`, `promptId`, `parentId` (или `null`), необязательный `beforeId` соседнего пункта; отсутствие/`null` — в конец соседей |
| `review.prompt.delete` | `id`, `promptId` — удаление пункта вместе с потомками |
| `review.finish` | `id`, необязательные `notes`, `intervalDays`; доступно после отметки всех конечных пунктов |

## Преобразование названий с путями

`review.update` с `id` и `nestBySeparator: " → "` явно преобразует плоский список с названиями вида `Личные → Здоровье → Врачи` в дерево. Идентификаторы и отметки исходных конечных пунктов сохраняются. Группы получают новые идентификаторы. Если исходный пункт одновременно является префиксом другого пути, преобразование отклоняется как неоднозначное. Уже вложенный список повторно не преобразуется.

Преобразование не запускается автоматически при чтении. До операции следует сохранить копию выбранного списка, после — проверить исходные идентификаторы, отметки и восстановленные полные пути. Остальные списки операция не затрагивает.
